# Trippone

App di viaggio personale, installabile su iPhone (PWA offline).

I contenuti sono cifrati (AES-256-GCM): senza la password questo repository
contiene solo file illeggibili. Il codice dell'app e' una pagina statica
senza framework ne' dipendenze esterne (Leaflet incluso in locale).

Installazione: aprire l'URL GitHub Pages in Safari, Condividi, "Aggiungi
alla schermata Home".
